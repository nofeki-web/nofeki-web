# NOFEKI Web — MVP

Sitio web estático de NOFEKI con:
- Landing corporativa.
- Presentación de NOFEKI OPS.
- Catálogo inicial de Microapps.
- Microapp NOFEKI Gastos funcional.
- Registro y eliminación de gastos.
- Reportes interactivos: total, movimientos, promedio, categoría principal y evolución mensual.
- Persistencia local con localStorage.

## Publicación
Sube `index.html` a cualquier hosting de sitio estático y apunta el dominio de NOFEKI a ese hosting.

## Importante
NOFEKI Gastos funciona inicialmente en el navegador del usuario. Los datos no salen del dispositivo. Para una V2 se puede agregar autenticación, base de datos, sincronización entre dispositivos, exportación y paneles avanzados.
